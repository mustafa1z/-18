    نقرة مزدوجة
    ⚙️ كيف يعمل؟ مكتبة MediaPipe تعمل بالكامل داخل متصفحك وتحدد ٢١ نقطة تشريحية في يدك من صورة الكاميرا (٣٠ مرة/ثانية)، ثم يحوّل الكود مواضع الإصبع إلى إحداثيات مؤشر ويصنّف شكل اليد إلى إيماءة عبر قياس المسافات بين المفاصل — كل هذا محلياً دون إرسال أي صورة أو بيانات إلى أي خادم.
    💡 ملاحظة مهمة حول التحكم الحقيقي بالنظام: المتصفحات (بأسباب أمنية صارمة) لا تسمح لأي صفحة ويب — أيًّا كانت لغتها — بتحريك مؤشر نظام التشغيل الحقيقي خارج النافذة. هذا البرنامج يمنحك تحكماً كاملاً داخل صفحته (سطح مكتب افتراضي تفاعلي بالنقر والسحب والتمرير والقوائم)، وفي الأسفل شرح لطريقة ربطه بسكربت بايثون صغير للسيطرة على النظام الحقيقي بالكامل إذا رغبت.
    🐍 التوسعة: التحكم في النظام الحقيقي عبر بايثون (للمتقدمين)
    فكرة الربط: يرسل هذا الملف إحداثيات المؤشر عبر WebSocket إلى سكربت بايثون يعمل على جهازك، فينفّذها على النظام باستخدام pyautogui: 
    # server.py — pip install websockets pyautogui
import asyncio, json, websockets, pyautogui

async def handler(ws):
    async for msg in ws:
        d = json.loads(msg)
        x, y = d.get("x"), d.get("y")
        if x is not None:
            pyautogui.moveTo(x * pyautogui.size()[0],
                             y * pyautogui.size()[1], duration=0)
        if d.get("click"):  pyautogui.click()
        if d.get("rclick"): pyautogui.rightClick()
        if d.get("scroll"): pyautogui.scroll(d["scroll"])

async def main():
    async with websockets.serve(handler, "localhost", 8765):
        await asyncio.Future()

asyncio.run(main())
    ثم في هذا الملف: افتحConsole المتصفح واتصل بـ new WebSocket("ws://localhost:8765") وأرسل الإحداثيات داخل دالة doClick/updateTarget. هكذا تتحول الأوامر من سطح المكتب الافتراضي إلى نظامك الحقيقي.
